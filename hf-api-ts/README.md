# Kalamalah Open Quran API (TypeScript)

Free, open REST API for Quran text, translations, fuzzy Arabic search, reciters, audio streams, word-by-word timing, Mushaf pages, and fonts.

- **Docs**: `/docs`
- **Base**: `/api/v1`
- **CORS**: Enabled for all origins (`*`), no API key required.
